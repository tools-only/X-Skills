## Description

!!! warning "Security Warning"
    Query parameter authentication is inherently insecure (CWE598). API keys in URLs may appear in proxy logs, browser history, and server access logs. Only use this authentication method when the upstream MCP server requires it (e.g., Tavily MCP).
