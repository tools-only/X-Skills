## Description

TimesFM (Time Series Foundation Model) is a pretrained decoderonly foundation model
developed by Google Research for timeseries forecasting. It works zeroshot — feed it
any univariate time series and it returns point forecasts with calibrated quantile
prediction intervals, no training required.
