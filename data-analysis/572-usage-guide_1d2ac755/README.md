## Description

This skill enables AI agents to query proteinprotein interaction (PPI) databases including STRING, BioGRID, IntAct, and OmniPath. Retrieves interaction partners, confidence scores, and functional enrichment for gene sets, then converts results into NetworkX graphs for downstream analysis.
