## Description

Dasel (DataSelect) is a singlebinary CLI tool and Go library for querying, modifying, and transforming structured data files. It solves the problem of needing separate tools (jq for JSON, yq for YAML, xmllint for XML) by providing one unified query syntax that works across all supported formats.
