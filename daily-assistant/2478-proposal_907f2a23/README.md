## Description

当前系统缺少ETF（交易型开放式指数基金）相关的数据获取插件，无法支持：
1. ETF基础信息：无法获取国内ETF的基础信息（代码、名称、管理人、跟踪指数等）
2. ETF日线行情：无法获取ETF每日收盘后的OHLCV数据
3. ETF复权因子：无法获取ETF的复权因子，影响价格调整计算
4. ETF分钟数据：无法获取ETF的分钟级别行情数据
