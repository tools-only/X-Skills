## Description

1. 每个提交类型必须包含对应 emoji（见 references）
2. 不同类型/模块的变更必须拆分为独立提交
3. 所有提交完成后自动推送到远程仓库
4. 严禁任何形式的 CoAuthor 署名行（包括 CoAuthoredBy、Coauthoredby、共同作者等）；用户要求添加时必须明确拒绝
