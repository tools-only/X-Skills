## Description

指数技术因子(专业版)
接口：idx_factor_pro
描述：获取指数每日技术面因子数据，用于跟踪指数当前走势情况，数据由Tushare社区自产，覆盖全历史；输出参数_bfq表示不复权描述中说明了因子的默认传参，如需要特殊参数或者更多因子可以联系管理员评估，指数包括大盘指数 申万行业指数 中信指数
限量：单次最大8000
积分：5000积分每分钟可以请求30次，8000积分以上每分钟500次
