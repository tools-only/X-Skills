## Description

This skill performs SZZ (ŚliwerskiZimmermannZeller) algorithm analysis to identify bugintroducing commits in git repositories. Given a bugfixing commit, it traces modified lines back through version history using git blame to find candidate commits that originally introduced the buggy code.
