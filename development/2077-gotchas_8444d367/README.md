## Description

Cause: Crossconnect not installed, RX/TX fibers reversed, wrong fiber type, or low light levels
Solution:
1. Verify crossconnect installed
2. Check fiber at patch panel
3. Swap RX/TX fibers
4. Check light with optical power meter (target > 20 dBm)
5. Contact account team
