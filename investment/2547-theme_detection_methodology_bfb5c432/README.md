## Description

The Theme Detector uses a 3Dimensional Scoring Model to identify, rank, and assess market themes. Unlike singlescore ranking systems, this approach separates the intensity of a theme (heat), its maturity stage (lifecycle), and the reliability of the signal (confidence) into independent dimensions.
